Uso previsto

Youber es una herramienta personal para gestionar y publicar contenido propio (o debidamente licenciado) en la cuenta de YouTube de su autor. No se ofrece como servicio a terceros.

Uso aceptable

  • Solo se publica contenido propio o con licencia.
  • No se automatizan interacciones ni se manipulan métricas.
  • Se respetan los Términos de Servicio de YouTube y las APIs de Google.
  • No se recopilan datos de terceros ni se eluden sistemas de seguridad.

Responsabilidad

El software se ofrece "tal cual", sin garantías. El autor es el único responsable del contenido que publica y de las credenciales que usa.

Limitación de responsabilidad

El autor no se hace responsable de daños derivados del uso de la herramienta, incluidas interrupciones del servicio de terceros o cambios en sus APIs.
